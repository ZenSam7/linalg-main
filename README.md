# учебная лаба по плюсам
CMake настроил на сборку гугл тестов (linalg_tests) и небольшой (навайбкоденной) демки для демонстрации оптимизаций применяемых в моей либе

сама либа [linalg-library](https://github.com/ZenSam7/linalg-library) идёт как подмодуль


также добавил в cmake подмодуля [linalg-library](https://github.com/ZenSam7/linalg-library) сборку моей либы в питоновскую библиотеку ~~**(зачем?)**~~. пример использования моей c++ либы через питон в файле `linalg_python_library.py` .
P.S. лично я компилирую через mingw на win10, и копирую получившуюся питоновскую либу `.pyd` и интерфейс для IDE `linalg.pyi` прямо в папку к другим либам в окружении в конде (если вы конду не юзаете, то ~~очень сочувствую~~ нейронка скажет как импортировать питоновскую либу в вашем случае)
